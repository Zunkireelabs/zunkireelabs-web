## Software Development Companies in Nepal

Software development remains Nepal's largest tech sector. These companies range from pure outsourcing operations to product-focused firms building their own IP.

This list names each company and its focus only; it is not a ranking and does not profile them.

- **Leapfrog Technology**: Full-stack development, mobile apps, cloud solutions
- **Deerwalk Services**: Healthcare software, data analytics, enterprise solutions
- **Verisk Nepal (formerly ISO Nepal)**: Insurance software, risk analytics, enterprise systems
- **F1Soft International**: Fintech, digital payments, banking software
- **Javra Software**: Outsourced development, e-commerce, web applications
- **Yomari Information Services**: GIS, mapping, government systems
- **LogPoint**: Cybersecurity, SIEM, threat detection
- **Yantra (formerly WebSurfer Nepal)**: Digital agencies, enterprise software, mobile apps
- **Proshore**: PHP development, web applications, European outsourcing
- **Dailo Technology**: Mobile development, iOS/Android, cross-platform apps
- **Incessant Rain Studios**: Game development, Unity, interactive media
- **Kazi Studios**: Game development, mobile games, AR/VR
- **Esewa / F1Soft Products**: Digital payments, mobile wallet, fintech platform
- **Thulo.com (Thulo Technology)**: E-commerce, marketplace platforms, logistics tech
- **WorldLink Communications**: ISP, network infrastructure, digital services
- **Young Innovations**: Civic tech, open data, development sector software
- **Truemark Technology**: Startup development, MVP building, product engineering
- **Cotiviti Technologies Nepal**: Healthcare software, payment integrity, analytics
