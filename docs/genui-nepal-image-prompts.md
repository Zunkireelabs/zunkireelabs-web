# Generative UI demo: Nepal image prompts

Save each image as WebP, 1600x900 (16:9), under `src/assets/images/genui-nepal/`, named exactly as below.
Until a file exists the demo shows a drawn placeholder, so you can add them one at a time.

Shared style line (append to every prompt):
"Photorealistic travel photography, natural light, rich detail, no text, no watermark, no people facing the camera, 16:9 composition with calmer space in the lower third so a title can sit on it."
