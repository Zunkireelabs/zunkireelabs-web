## Platform

## Users

Buyer/user varies by industry vertical (no single primary persona):

- **AI for Education** — education consultancies / study-abroad recruitment firms (e.g. Admizz) managing application pipelines and partner-college relationships.
- **AI for Agencies** — IT and professional services agencies running deal pipelines, proposals, project delivery, and resourcing (ZunkireeLabs runs its own ops on this; also serves Mobilise).
- **AI for Healthcare** — Australian healthcare providers (hospitals, aged care, community care) needing compliant workforce/rostering, plus healthcare professionals and employers using the recruitment/job-matching side.
- **AI for Real Estate** — CRE sponsor firms raising capital from investors (offerings, commitments, data rooms). No named client yet.

## Product Purpose

ZunkireeLabs builds production-grade, multi-tenant AI systems (CRM + industry-specific modules, RAG search, AI orchestration) for four core industry verticals, plus custom AI/software development for a broader range of clients. Success is a live, production system running for the client — not a prototype or pilot.

## Positioning

Industry-first, not service-first (Kore.ai-style: "AI for Education / Agencies / Healthcare / Real Estate"). Each vertical bundles a flagship pre-built application, reusable accelerators, and the shared platform layer underneath — competitors sell either generic AI consulting or single-purpose software, not an industry-tenanted AI OS with a live flagship deployment already proving the model in each vertical.

## Operating Context

- **Platform layer powering every vertical**: multi-tenant AI CRM with per-industry modules; **Zunkiree Search** (flagship RAG search product, powers the Admizz education deployment); **Orca** (AI orchestration layer coordinating agent workflows across CRMs, email, marketing tools).
- Per-vertical workflows: education application pipeline (document collection → offer → visa → enrolled); agency delivery pipeline (deal → proposal → project cockpit → time/resourcing); healthcare compliance-gated shift rostering with credential/licensure tracking; CRE capital-raise workflow (offerings, investor commitments, data room).
- Other live client work outside the four core verticals (breadth signal, not dedicated pages): food & beverage/restaurant, hospitality booking, spa/salon booking, cleaning ops (Khems Cleaning), construction (Khushbu Nirman Sewa), wholesale B2B/ERP, e-commerce/agentic commerce, investment analytics (Rapid Investment), IT/cloud services (CoreCloud365).
- A separate **consumer real estate marketplace** (property listings, home loans, fractional investing, Nepal retail buyers) exists and must not be conflated with the CRE capital-raise vertical above.
